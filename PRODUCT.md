# Product

## Register

product

## Users

Desktop users who live in a file manager for hours at a time — developers and power users on Windows, macOS, and Linux. Primary task: navigate, inspect, and organize files quickly and safely. They judge the app on speed, density, predictability, and whether it feels native to their OS.

## Product Purpose

Flux Files is a native Rust/egui file manager that combines Explorer familiarity, Finder polish, and Dolphin productivity without web tech or a permanent indexer. Success: large directories stay responsive, destructive operations are safe, and the UI disappears into the task.

## Brand Personality

Modern, minimal, elegant, fluent, refined, native-feeling, lightweight, purposeful. Quiet confidence — restrained details, precise spacing, clear typography. Contemporary and comfortable for extended use.

## Anti-references

- Generic AI/SaaS dashboard aesthetics: huge rounded cards, purple-blue gradients, neon accents, glow shadows, oversized headings, dashboard metric tiles, decorative empty components.
- Traditional utility-software look: cramped modals, tiny labels, boxed toolbar buttons, hard borders everywhere.
- Marketing-page flashiness: heavy motion, ornamentation, cartoon illustrations.

## Design Principles

1. Earned familiarity — standard affordances, consistent component vocabulary; the tool disappears into the task.
2. Surfaces separate by subtle tonal steps, not aggressive borders or cards.
3. Accent color is for primary actions, selection, and state — never decoration.
4. Density where it serves the task (file lists), breathing room where it aids comprehension (settings, dialogs).
5. Every interactive element has visible hover/press/focus/disabled states; nothing is clipped or off-screen at supported window sizes.

## Accessibility & Inclusion

Keyboard-navigable settings, menus, and dialogs; Escape/Enter behave predictably; text scaling via UI scale setting; status is never conveyed by color alone (icon/glyph + text); readable contrast in both light and dark themes.
